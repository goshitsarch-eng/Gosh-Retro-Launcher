# WfW UI font provenance

The `WfWSans` webfonts are redistributed copies of the independently recreated FontStruction **MS Sans Serif** and **MS Sans Serif Bold** by `lou`, obtained from the `jdan/98.css` repository.

- Source: <https://fontstruct.com/fontstructions/show/1384746>
- Bold source: <https://fontstruct.com/fontstructions/show/1384862>
- Conversion source: <https://github.com/jdan/98.css/tree/main/fonts>
- Font license: Creative Commons Attribution-ShareAlike 3.0
- Conversion/project license: MIT

The original font files are recreations and are not copied from Microsoft Windows. `LICENSE.txt` and `README-source.txt` are included beside the webfonts as required by the source archive. Within this project the family is renamed to `WfWSans` to avoid claiming that it is a Microsoft-distributed font.

WfW rendering uses the recreated face at its intended 11 logical-pixel bitmap size. Title captions use the supplied bold recreation. The previous `W95FA` files remain only for the untouched Win95 path.
