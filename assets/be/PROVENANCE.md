# BeOS-style icon provenance

The PNGs in this directory come from the Claude Design `iconsbe/` set created
for this project. They are original artwork inspired by the BeOS R5 look
(yellow folders, Deskbar leaf, soft shadows) and are not extracted, traced or
derived from Be Inc. / Haiku resources.

`tools/import_design_icons.py` handles the import. The project does not claim
pixel identity with BeOS artwork.
